What each target can actually see

Namespace + macro resolution matrix for Clojure, ClojureScript and Squint.

The question Can one shared facade namespace be backed by a different implementation per target, with byte-identical portable application code calling it? Before we can argue about where backend selection is allowed to live, we have to know what each compiler is even capable of seeing: which file extensions it reads, and whether it finds a macro without being told explicitly.

How to read this page Every verdict is shown twice: OBSERVED is what a real compiler actually did (ClojureScript 1.12.42, Squint 0.14.210). MODEL is what this page's little rule engine predicts. Where the two disagree, the model is wrong — that is the interesting cell. Cells marked “not observed” were never actually run.
